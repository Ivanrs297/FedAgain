## Workstream B — the code

- **Run one experiment:** edit `config.py`, then `python main.py` (from repo root).
- **Runners** (in `scripts/`, run from repo root) rewrite `config.py` per run and
  subprocess `main.py`. **They leave `config.py` modified → `git checkout config.py`
  when done.**
- **Resilient tracking** (`src/tracking.py`): every run writes incrementally to
  `results/{experiment_ledger.csv, runs/<key>.json, rounds/<key>.csv, ledger.jsonl}`.
  Completed runs are **skipped on resume** (set `EXPERIMENT_FORCE=1` to rerun);
  crashes are marked `failed` (via atexit/excepthook) so they retry, not skip.
- **`config.SEED`** controls partitioning, corrupted-client selection, per-client
  corruption, and training RNG (threaded through `load_data`); part of the run key.
  Sweep seeds with the runners' `--seeds 42 43 44`.
- **`config.NUM_WORKERS=8`** parallelizes the CPU-bound image corruption (~2.7x
  speedup; clients train sequentially so no oversubscription).
- **Strategies** (dispatched in `main.py`): FedAvg, FedProx, FedYogi, FedMedian,
  Bulyan, **FedBN**, **Scaffold**, **MOON**, **FedAgain**.
  - FedBN keeps per-client BatchNorm local (state in `client_bn_state`).
  - MOON: `train_moon` in `src/client.py`, per-client prev model in `client_prev_state`.
  - Scaffold: `train_scaffold`, control variates `scaffold_c_global`/`scaffold_c_local_state`;
    **uses plain SGD** (momentum breaks the control-variate estimate — diverges).
  - FedAgain trust formulation is pluggable via `src/strategies/trust.py`
    (`FEDAGAIN_TRUST_MODE`: combined_mult | benchmark_only | divergence_only |
    additive | weighted_additive) — used for the #2/#3 ablation.
- **Tests:** `python tests/test_trust.py` (6), `python tests/test_tracking.py` (4).
- Env: numpy, torch+CUDA, datasets present under `data/`. `flwr` not needed.

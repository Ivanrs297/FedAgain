 fedagain.py - Complete FedAgain Implementation
Trust Weight: T_k = 1 / (E_k × D_k + ε)
E_k (Benchmark Error): Error on incoming global model (computed by each client)
D_k (Divergence): L2 norm of parameter difference ||w_k - w_global||
ε (Epsilon): Small constant for numerical stability
2. Integration into Main Pipeline
Clients compute benchmark error on their validation set
Server computes divergence and trust weights
Aggregation uses trust-weighted average

How FedAgain Works:
Each client receives global model → computes benchmark error E_k (before training)
Client trains locally → sends updated parameters back
Server computes divergence D_k = distance between client and global model
Server computes trust weight T_k = 1/(E_k × D_k + ε)
Low error + small divergence = high trust (larger weight)
High error or large divergence = low trust (smaller weight)
Aggregation: Trust-weighted average instead of simple average

📚 FedAgain Implementation Explanation
Overview:
FedAgain is a trust-based federated learning strategy that assigns weights to clients based on their trustworthiness. Clients with better performance and smaller model updates get higher trust weights.
🔑 Key Components:
1. Trust Weight Formula:
Where:
T_k: Trust weight for client k
E_k: Benchmark error (how bad the client performed on validation data)
D_k: Divergence (how much the client's model changed from global model)
ε: Small constant (1e-6) for numerical stability
Intuition:
✅ Low error + Small divergence → High trust → Higher weight
❌ High error + Large divergence → Low trust → Lower weight

What happens:
Client receives global model
Tests it on their validation set (10% of client's data)
Computes error rate = 1 - accuracy
This measures: "How well does the global model work on my data?"
